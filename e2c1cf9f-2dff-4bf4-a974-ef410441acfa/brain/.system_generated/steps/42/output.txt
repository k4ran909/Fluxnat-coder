The **Dolphin 3.0 Qwen 2.5 3B** model is part of the Dolphin 3.0 collection curated and trained by Cognitive Computations (led by Eric Hartford)[1][2].

### Hugging Face Repository
The primary (base) model can be found on Hugging Face under the organization `dphn`:
*   **Model Name:** `dphn/Dolphin3.0-Qwen2.5-3b`[1][3]

For users looking for pre-quantized versions (GGUF format) suitable for local inference engines like LM Studio or llama.cpp, you can typically find them under these accounts:
*   `bartowski/Dolphin3.0-Qwen2.5-3b-GGUF`[2][4]
*   `QuantFactory/Dolphin3.0-Qwen2.5-3b-GGUF`[5][6]

### Ollama
To run this model directly in **Ollama**, you can use community-provided ports. One common repository for this model on Ollama is:
*   **Command:** `ollama run nchapman/dolphin3.0-qwen2.5:3b`[2][7]
*   Alternatively, other users have uploaded versions such as `sam860/dolphin3-qwen2.5:3b-Q4_K_M`[8][9].

### Key Characteristics
*   **Uncensored:** As part of the Dolphin series, this model is designed to be "uncensored" and steerable, meaning it is intended to follow the user's instructions without imposing external moralizing, disclaimers, or alignment guidelines[1][10].
*   **Purpose:** It is optimized for general-purpose tasks, including coding, mathematics, agentic workflows, and function calling[1][7].
